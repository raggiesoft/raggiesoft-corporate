Official licensing and open-source software portal for **Michael P. Ragsdale** (`https://corporate.raggiesoft.com`, `301` target of `https://raggiesoftmedia.com`), separating MIT open-source software releases (**Stardust Engine CMS** and **RaggieSoft StoreTrainer**) and commercial music synchronization clearance from fictional narrative catalogs.

- **Production Domain**: `https://corporate.raggiesoft.com` (Vanity `301` Redirect: `https://raggiesoftmedia.com`)
- **Tech Stack**: Zero-dependency **Node.js ESM Static Site Generator (`scripts/build.mjs`)** + **Bootstrap 5.3.8**
- **Accessibility**: Code-level WCAG 2.1 AA & Section 508 web compliance (`prefers-color-scheme: light | dark`)
- **Licenses**: MIT License (Code) & CC BY-SA 4.0 (Creative Content)
